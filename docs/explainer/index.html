What is nyx-phone-agent and what is it like to use?

Long image

A

Answer

Nyx Phone Agent is an unfinished, paused prototype of an Android assistant. You type or speak a request in a chat screen. A cloud model picks a phone tool, and Nyx acts and tells you what it did.

  1. The working path is one sideloaded app, agent-launcher, that needs your own OpenRouter API key.1
  2. Its tools open apps, change Wi-Fi, Bluetooth, volume or brightness, read or send SMS, speak, and build small web apps on the phone.2
  3. The call receptionist, sales pipeline and on-device voice engine exist as code but are not part of the build.3
  4. The owner has closed the project; the latest main-branch CI run was cancelled, so no build is confirmed green.4

What happens when you ask Nyx to build an app?

Diagram structure
  • You you
  • Nyx app app
  • Cloud model model
  • Phone tools phone
  • you → app · Paste OpenRouter key, pick model
  • you → app · Type or speak a request
  • app → model · Chat history + tool list
  • model → app · Call build_app(name, spec)
  • app → model · Generate one HTML file
  • model → app · Self-contained HTML
  • app → phone · Save and open in WebView
  • app → you · Reply, spoken aloud
  • you → app · Yes, add it to home screen
  • app → phone · pin_app: shortcut request
  1. Paste key, pick model ↗

    The screen asks for an OpenRouter key and offers 12 models; the default is openai/gpt-4o-mini.

  2. Type or speak ↗

    Tap [run], or [mic] to use Android speech recognition.

  3. Model picks a tool ↗

    The model gets the chat and every tool; it may call up to 6 tools per request.

  4. Save and open ↗

    build_app saves the HTML under the app's private files and opens it full screen.

  5. Reply, spoken aloud ↗

    Nyx says what it did; each tool call shows as a cyan [tool] line.

  6. Shortcut request ↗

    Android shows its own "Add to Home screen" dialog before placing the icon.

agent-launcher is the app a person would use. The daemon only keeps a notification alive; the conversation runs in the chat screen.

Is there a meeting bot or call transcription?

The GitHub description promises more than the code holds

The repo description mentions a meeting bot, transcription and telephony. No meeting-bot code exists. Call handling is a 33-line class that auto-answers calls, and it sits in an unbuilt module. Transcripts appear only as text inputs to the sales pipeline tests.
